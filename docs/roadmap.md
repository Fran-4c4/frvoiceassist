# Hoja de ruta

## Completado

- Síntesis local con Qwen3-TTS y clonado desde un audio de referencia.
- Interfaz web para gestionar voces, guiones y audio.
- Reproducción por frases, preparación en segundo plano y caché local.
- Salida mediante un cable de audio virtual para aplicaciones de videollamada.

## Próximos pasos

1. Mejorar el tiempo de inicio y generación, y evaluar reproducción progresiva.
2. Añadir un modo de interpretación local: micrófono → transcripción → traducción → voz clonada.
3. Incorporar un glosario configurable y mostrar transcripción y traducción en la interfaz.
4. Medir rendimiento en varios entornos y documentar resultados reproducibles.

## Mejoras futuras

- Streaming de audio cuando el motor ofrezca una interfaz estable.
- Motores intercambiables de transcripción, traducción y síntesis.
- Herramientas adicionales para preparar y reproducir presentaciones.
- Autenticación antes de permitir acceso desde otros equipos.
